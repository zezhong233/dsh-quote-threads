# 引用追问（Quote Threads）

在 DSH 回答中选中一段文字，创建独立、可持续的子问答。母会话仍按普通时间线显示，子问答只在需要时展开。

## 使用

1. 在一条已完成回答的正文中选中文字。
2. 点击这条回答操作区的「引用追问」分支图标。
3. 在输入框上方确认引用原文，输入问题并发送。
4. 回答下方出现「N 条引用追问」。展开列表后，每条引用先显示折叠摘要，再点击单条查看完整问答。
5. 子问答下方可以继续提问；内联回答使用 DSH 原生 Markdown 渲染，支持 LaTeX。点击「打开完整对话」可进入原生 DSH 子会话，查看工具调用等完整内容。
6. 左侧「引用地图」按层级列出当前工作区的引用会话。

在子会话的原生完整对话中，也可以再次选中回答文字并创建下一层引用追问。含 KaTeX 公式的选区会提取为单份 TeX，引用原文和问题回答都使用原生 Markdown 渲染，避免 MathML 与视觉字符重复断行。母回答中已经提问的片段会用不同颜色的下划线标出，公式按整个公式节点标注。

## 数据与恢复

- 子问答是 DSH 原生的持久 continuable subagent session。
- 母子关系保存在母会话的 `subagentCatalog` 中。
- 首条用户消息含版本化引用记录，包括母会话、母消息、轮次、事件序号、选区范围、原文和问题。
- 插件不维护独立关系数据库。刷新或重启后，关系树从会话日志重新构建。
- `delivery: caller` 防止子问答完成通知插入母会话时间线。

## 当前显示边界

内联卡片订阅实时事件，助手回答使用 DSH 原生 `MarkdownText`，支持 Markdown 和 LaTeX。工具卡片和子会话原生操作请使用「打开完整对话」。
